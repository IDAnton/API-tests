| Критерий                 | Selenide                                                                                                                                                                                                                                         | Selenium                                                                                                                  |
|:-------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------|
| **Настройки браузера**   | Настройка через `Configuration`,  нет явной привязки к конкретному браузеру.                                                                                                                                                                     | Создание объектов конфигурации браузера (`new ChromeOptions().addArguments()` это привязывает код к конкретному браузера. |
| **Page object**          | Абстракция через `SelenideElement`, ввод данных одним методом `SelenideElement.setValue()`, декларативные проверки `shouldBe(visible)`. В случае "протухания" ссылки на элемент под капотом автоматически заново производится поиск по локатору. | Много бойлерплейт кода по типу: `wait.until(ExpectedConditions.visibilityOfElementLocated())`.                            |
| **Код тестов**           | `Fluent API` (цепочка вызывов методов), хорошо читается бизнес логика.                                                                                                                                                                           | Стандартыне громоздкие `Assertions`.                                                                                      |
| **Управление драйвером** | Автоматичесоке закрытие/октрытие драйвера браузера.                                                                                                                                                                                              | Необходимо самому прописывать в `@BeforeEach`, `@AfterEach`.                                                              |
